📋 Cara Menggunakan Export

  1. Kelola foto di tab Portfolio atau Beranda
  2. Kembali ke halaman ini → klik tab yang sesuai di bawah
  3. Salin kode yang dihasilkan
  4. Paste ke file: gallery-script.js atau index.html
  5. Push ke GitHub → perubahan live di website!

⚠️ Untuk foto yang di-upload langsung, pindahkan file ke folder assets/compressed/ terlebih dahulu.
